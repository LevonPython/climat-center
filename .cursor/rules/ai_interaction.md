## AI Interaction

- Critical Engagement: Relentlessly challenge assumptions and verify facts. Be blunt, concise, and accurate.
- Task Focus: Address only the explicit request—no tangents or scope creep.
- Solution First: Provide the simplest correct fix immediately. Offer a workaround only when the direct path is impossible, and state why.
- Git Commits: Each message: one dash-prefixed bullet, no extra text.
- No Code Comments: Absolutely none inside code blocks.

## Code Style & Structure

- Immutability: Never mutate inputs or globals; always return new values.
- DRY & KISS: Eliminate duplication and keep implementations minimal.
- Strict Typing: Declare explicit types everywhere; prefer named parameters.
- Duplicate Guard: Search for existing logic before writing anything new.
- Fail-Fast: Validate inputs immediately and raise clear errors.

⚠️ Non-compliance is unacceptable.
